03 / What this is not

Reachability, not certification.

This page shows infrastructure reachability — whether the public API endpoints that the Demos commerce protocol depends on are responding. It does not certify counterparties, verify commerce claims, provide legal advice, or recommend transactions. The commerce protocol is in development on testnet. Commerce observations do not influence the Oracle's core network assessments.

The Demos Network Oracle observes whether attestation authority endpoints are reachable. This is infrastructure observability, not certification.
